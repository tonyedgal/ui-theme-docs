UI-Theme adds light mode, dark mode, system mode, and named color palettes to your app. It also adds animated theme changes on the web and on native devices.

UI-Theme has three packages. Each package targets one platform family.

| Platform                       | Package       | Status                     |
| ------------------------------ | ------------- | -------------------------- |
| React on the web               | `uitheme-web` | Stable. Version 1.1.0      |
| Vue 3 and Nuxt 4               | `uitheme-vue` | Alpha. Version 0.1.0-alpha |
| React Native and Expo (native) | `uitheme-rn`  | Alpha. Version 0.1.0-alpha |

## What UI-Theme does

- It stores the user choice for appearance (`light`, `dark`, or `system`).
- It stores the user choice for a named color palette. The palette is separate from the appearance.
- It restores both choices when the app starts.
- It plays an animated change when the user switches. The web packages use the View Transitions API. The native package uses Reanimated and Skia.
- It respects the reduced motion setting of the user.
